### Установка через менеджер пакетов системы

##### Рекомендуемый способ установки

<Tabs items={["Homebrew", "Go install", "Binary Download"]}>
  <Tab value="Homebrew">
    #### Homebrew

    Можно установить бинарный релиз в macOS через Homebrew:

    ```bash
    brew install easyp-tech/tap/easyp
    ```

    `Work in progress` — поддержка других системных менеджеров (apt, yum, pacman и т.д.) в процессе.
  </Tab>
  <Tab value="Go install">
    #### Требуется Go 1.24 или новее

    Установка последней стабильной версии EasyP через Go toolchain:

    ```bash
    go install github.com/easyp-tech/easyp/cmd/easyp@latest
    ```
  </Tab>
  <Tab value="Binary Download">
    #### Сборка из исходников

    1. Клонирование репозитория:

    ```bash
    git clone https://github.com/easyp-tech/easyp.git
    ```

    2. Сборка с помощью Go:

    ```bash
    go build ./cmd/easyp
    ```
  </Tab>
</Tabs>

## Особые указания по локальной сборке

Установка через пакетные менеджеры предпочтительнее локальной сборки вручную, так как пакетные менеджеры обеспечивают:
- Автоматические обновления и патчи безопасности
- Улучшенную интеграцию с операционной системой
- Упрощённый процесс установки и удаления
- Проверенные бинарные сборки
