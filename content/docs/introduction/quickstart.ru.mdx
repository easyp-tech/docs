---
title: "Быстрый старт"
description: "Создание protobuf-модуля и генерация кода в EasyP v1 nightly."
---

Установите [явно выбранный v1 nightly](/ru/docs/introduction/install#явная-установка-v1-nightly) и убедитесь, что доступен Git. Плагин `go` использует `protoc-gen-go` из `PATH`, если он установлен; иначе EasyP запускает встроенный WASM-генератор.

## 1. Создайте модуль

```bash
# Выберите nightly из инструкции по установке для текущего терминала.
export PATH="$HOME/.local/share/easyp-nightly/bin:$PATH"
easyp --version

mkdir contracts && cd contracts
git init
easyp init --module github.com/acme/contracts
```

`init` создаёт три файла: `protobuf.mod` для модуля, `easyp.yaml` для политик линтинга и проверки совместимости, `easyp.gen.yaml` для генерации. Перед заменой существующего файла EasyP спрашивает пользователя. Автоматическая миграция зависимостей Buf в пилотную версию не входит.

## 2. Добавьте proto-файл

```bash
mkdir -p proto/acme/v1
```

Создайте `proto/acme/v1/hello.proto`:

```proto
syntax = "proto3";
package acme.v1;
option go_package = "github.com/acme/contracts/gen/go/acme/v1;acmev1";

message Hello {
  string name = 1;
}
```

Укажите корень исходников в `protobuf.mod`:

```text
module github.com/acme/contracts
roots proto
```

## 3. Настройте генерацию

Замените пустой список плагинов в `easyp.gen.yaml`:

```yaml
version: v1
generate:
  modules: [github.com/acme/contracts]
plugins:
  - name: go
    out: ./gen/go
    opts:
      paths: source_relative
```

## 4. Запустите команды

```bash
easyp mod tidy
easyp generate
easyp lint --path proto
```

`mod tidy` создаёт `protobuf.lock`. Если исходники импортируют другой Git-модуль, сначала добавьте в `protobuf.mod` строку `require module version`. Позже `mod download` скачает точные коммиты из lock. Храните `protobuf.mod` и `protobuf.lock` вместе с исходниками в репозитории.

Подробности: [конфигурация](/ru/docs/cli/configuration), [генерация](/ru/docs/cli/generator), [зависимости](/ru/docs/cli/package-manager).
