---
title: "Quickstart"
description: "Create a protobuf module and generate code with EasyP v1 nightly."
---

Install an [explicit v1 nightly](/docs/introduction/install#opt-into-v1-nightly) and make sure Git is available. The `go` plugin uses `protoc-gen-go` from `PATH` when installed, otherwise EasyP uses its bundled WASM generator.

## 1. Initialize a module

```bash
# Use the nightly installed in the installation guide for this terminal session.
export PATH="$HOME/.local/share/easyp-nightly/bin:$PATH"
easyp --version

mkdir contracts && cd contracts
git init
easyp init --module github.com/acme/contracts
```

`init` creates three files: `protobuf.mod` for the module, `easyp.yaml` for lint and breaking policies, and `easyp.gen.yaml` for generation. If a file already exists, EasyP asks before replacing it. Automatic migration from Buf dependencies is not part of the pilot.

## 2. Add a proto file

```bash
mkdir -p proto/acme/v1
```

Create `proto/acme/v1/hello.proto`:

```proto
syntax = "proto3";
package acme.v1;
option go_package = "github.com/acme/contracts/gen/go/acme/v1;acmev1";

message Hello {
  string name = 1;
}
```

Set the module's source root in `protobuf.mod`:

```text
module github.com/acme/contracts
roots proto
```

## 3. Configure generation

Replace the empty plugin list in `easyp.gen.yaml`:

```yaml
version: v1
generate:
  modules: [github.com/acme/contracts]
plugins:
  - name: go
    out: ./gen/go
    opts:
      paths: source_relative
```

## 4. Run the commands

```bash
easyp mod tidy
easyp generate
easyp lint --path proto
```

`mod tidy` creates `protobuf.lock`. Add `require module version` lines to `protobuf.mod` before running it when your sources import another Git module. `mod download` later fetches the exact locked commits. Commit `protobuf.mod` and `protobuf.lock` alongside the source files.

For a full field reference, see [configuration](/docs/cli/configuration), [generation](/docs/cli/generator), and [dependencies](/docs/cli/package-manager).
