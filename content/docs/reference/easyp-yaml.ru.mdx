title: "Справочник easyp.yaml"
description: "Полная спецификация файла easyp.yaml, управляющего правилами линтинга продюсера, проверками ломающих изменений, исключениями путей и наследованием политик."
---

Файл `easyp.yaml` определяет **конфигурацию политик на стороне продюсера** для репозиториев Protobuf-схем. Он задаёт стандарты линтинга, проверки ломающих изменений относительно Git-baseline и исключения замечаний. Каскадирование по директориям работает; явные ссылки `extends` оставлены до определения правил разрешения.

Файлы `easyp.yaml` каскадируются по иерархии директорий: для каждого файла `.proto` EasyP ищет ближайший `easyp.yaml` вверх по дереву каталогов и применяет его правила.

## Пример конфигурации

```yaml
version: v1

linters:
  default: STANDARD
  enable:
    - ENUM_VALUE_PREFIX
    - RPC_REQUEST_RESPONSE_UNIQUE
  disable:
    - PACKAGE_VERSION_SUFFIX

linters-settings:
  ENUM_ZERO_VALUE_SUFFIX:
    suffix: UNSPECIFIED
  SERVICE_SUFFIX:
    suffix: Service

issues:
  exclude-rules:
    - linters:
        - FIELD_LOWER_SNAKE_CASE

breaking:
  baseline: git:main
  ignore:
    - gen
```

## Каскадирование по директориям

EasyP использует **правило ближайшего файла**: при проверке `.proto` файла EasyP ищет `easyp.yaml` вверх по дереву директорий.

```text
proto/
├── easyp.yaml          # Политика STANDARD применяется к корню и user/
├── user/
│   └── v1/user.proto
└── legacy/
    ├── easyp.yaml      # Ослабленная политика MINIMAL только для legacy/
    └── old.proto
```

Секция берётся целиком из ближайшего определяющего файла без частичного слияния.

В v1 `breaking.baseline` выбирает Git-ветку для существующего checker EasyP. Набор его проверок не меняется. Выбор категорий и фильтрация нестабильных пакетов требуют отдельного определения правил и пока не активны. `issues.exclude-rules` с `path` сейчас выдаёт ошибку; правила без `path` работают без неявного выбора базы для glob. `linters.extends` и `breaking.extends` тоже пока выдают ошибку: ещё не определены Git ref, путь к политике, приоритет слияния и способ фиксации зависимости.
