Файл `protobuf.lock` — это автоматически генерируемый артефакт, создаваемый командами управления зависимостями EasyP (`easyp get`, `easyp mod tidy`, `easyp mod update`). Он фиксирует точный транзитивный граф зависимостей для обеспечения **100% герметичных и воспроизводимых сборок** во всех локальных окружениях и в CI.

## Команды жизненного цикла

- `easyp get <модуль>[@версия|@коммит]`: Добавляет прямое требование, записывает его транзитивные требования как indirect и обновляет `protobuf.lock`.
- `easyp mod tidy`: Сканирует импорты, дописывает транзитивные зависимости и перегенерирует `protobuf.lock`.
- `easyp mod update`: Обновляет зависимости с тегами до свежих совместимых релизов, требования без версии — до Git HEAD, сохраняет явно закреплённые хеши и обновляет `protobuf.lock`.
- `easyp mod download`: Наполняет локальный кэш строго по `protobuf.lock` без обращения к внешним реестрам.

`hash` вычисляется алгоритмом Go `dirhash.Hash1` по всем обычным файлам, отслеживаемым Git в коммите `commit`, с путями относительно корня репозитория. EasyP проверяет этот дайджест при скачивании и при чтении существующего кэша. Если нужного коммита в кэше нет, доступ к Git-репозиторию всё ещё необходим.
