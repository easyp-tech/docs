## Endpoints

| Port (binary / chart) | Path | Content |
|---|---|---|
| 23411 / 8081 | `/metrics` | Prometheus exposition. Always on. |
| 23412 / 8082 | `/live` | Liveness. 200 once the process is up; checks nothing else. |
| 23412 / 8082 | `/` | Readiness. 200 while PostgreSQL answers, 503 otherwise and during start. |

Point liveness probes at `/live` and readiness at `/`. Using readiness for
liveness restarts the pod on every database outage.

## Metrics

All names carry the `easyp_` prefix. Most are registered at start; those marked
*lazy* appear after their first event, and the cache metrics only when object
storage is configured.

## Traces

Set `telemetry.otlp_endpoint` (or `OTEL_EXPORTER_OTLP_ENDPOINT`) to an OTLP gRPC
collector. The core, the registry and each plugin run are wrapped in spans;
`pool.Get` records the time spent queued. Empty endpoint: no exporter is built
and nothing is attempted.

## Profiles

Set `telemetry.pyroscope_endpoint` for continuous profiling with Pyroscope.

## Logs

Structured JSON on stdout. Every start logs `configuration resolved` with the
settings that differ from defaults, secrets redacted. Worth alerting on in your
log system: `gRPC server is running WITHOUT TLS`,
`lowered to the licence tier's limit`, `licence expired`, `audit enqueue timed out`.

## Alerts

The Helm chart ships a `PrometheusRule` (`prometheusRule.enabled=true`, needs the
Prometheus Operator CRDs). Every alert carries a `runbook_url` pointing at
`prometheusRule.runbookBaseUrl` plus an anchor named after the alert.

| Alert | Fires when | Runbook |
|---|---|---|
| EasypLicenceExpiringSoon | Licence expires within `licenceExpiryWarningDays` (14) | [link](/docs/api-service/runbooks#easyplicenceexpiringsoon) |
| EasypLicenceInGrace | `easyp_license_in_grace == 1` for 15m | [link](/docs/api-service/runbooks#easyplicenceingrace) |
| EasypGenerationsRejected | `rate(easyp_pool_generations_rejected_total[5m]) > 0` for 5m | [link](/docs/api-service/runbooks#easypgenerationsrejected) |
| EasypGenerationQueueSaturated | `easyp_pool_generations_waiting > 0` for 10m | [link](/docs/api-service/runbooks#easypgenerationqueuesaturated) |
| EasypPluginCacheAtLimit | cache bytes / limit > `cacheUsageWarningRatio` (0.95) for 30m | [link](/docs/api-service/runbooks#easypplugincacheatlimit) |
| EasypAuditEventsLost | `rate(easyp_audit_events_lost_total[5m]) > 0` for 5m | [link](/docs/api-service/runbooks#easypauditeventslost) |
| EasypAuditMaintenanceStale | no successful partition maintenance for 24h | [link](/docs/api-service/runbooks#easypauditmaintenancestale) |
| EasypAuditDefaultPartitionUsed | `easyp_audit_default_partition_used == 1` for 15m | [link](/docs/api-service/runbooks#easypauditdefaultpartitionused) |
| EasypGenerationErrorRate | error ratio > `generationErrorRatio` (0.05) for 10m | [link](/docs/api-service/runbooks#easypgenerationerrorrate) |
| EasypPanics | `increase(easyp_panics_total[5m]) > 0` | [link](/docs/api-service/runbooks#easyppanics) |
| EasypAuthFailures | `rate(easyp_auth_failures_total[5m]) > authFailureRate` (0.5) for 10m | [link](/docs/api-service/runbooks#easypauthfailures) |

The compose stack adds host and edge alerts, evaluated by its own Mimir from what
Grafana Alloy collects — EasypHostDiskLow, EasypHostDiskFillingUp, EasypHostMemoryLow,
EasypTargetDown, EasypServiceMissing, EasypCertificateExpiringSoon — in
`deploy/observability/mimir/rules/anonymous/host.yaml`. They are also in
[Runbooks](/docs/api-service/runbooks#the-host).

`ServiceMonitor` (`serviceMonitor.enabled=true`) scrapes `/metrics` every 30 s.
