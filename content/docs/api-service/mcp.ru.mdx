---
title: "MCP-эндпоинт"
description: "Необязательный эндпоинт Model Context Protocol: что он отдаёт, как включить и что он обходит."
---

Сервис может отдавать эндпоинт [Model Context Protocol](https://modelcontextprotocol.io),
чтобы ИИ-инструменты могли узнать, какие плагины и версии есть в развёртывании —
например, при написании `easyp.yaml`.

## Что он отдаёт

Один инструмент, `plugins_list`: каталог плагинов с необязательными фильтрами
`group`, `name`, `version` и `tags`, постранично — как gRPC-вызов `Plugins`. Он
сгенерирован из того же proto-описания и возвращает те же данные.

Только чтение. Генерировать код, регистрировать, менять и удалять плагины через
него нельзя.

## Как включить

По умолчанию выключен.

| Где | Настройка |
|---|---|
| YAML | `mcp.enabled: true` |
| Окружение | `MCP_ENABLED=true` |
| Helm | `--set mcp.enabled=true` (заодно публикует порт контейнера и Service) |

Эндпоинт — `http://<host>:<server.port.mcp>/mcp`: порт 23413 по умолчанию, 8083 в
Helm-чарте, транспорт streamable HTTP. Когда он выключен, сервис пишет в лог
`MCP endpoint disabled; set mcp.enabled to serve it`, и порт никто не слушает.

Конфигурация клиента для инструментов, читающих карту `mcpServers`:

```json
{
  "mcpServers": {
    "easyp": { "url": "http://localhost:23413/mcp" }
  }
}
```

## Что он обходит

MCP-listener — обычный HTTP вне цепочки gRPC-интерсепторов: без TLS, без rate
limit, без лимита одновременных запросов на клиента, без аудита. Он не отдаёт
ничего сверх анонимного gRPC-вызова `Plugins`, поэтому по умолчанию может быть
анонимным, — но это решение, и пока вы его не приняли, эндпоинт выключен.

С `auth.require_authentication: true` эндпоинт требует тот же bearer-токен, что и
gRPC, и без него отвечает 401.

Отдавайте его внутри доверенной сети или за ingress, который терминирует TLS.

## Проверка

В репозитории сервиса есть smoke-клиент:

```bash
go run ./cmd/mcp-smoke --endpoint http://localhost:23413/mcp
```

У реестра Buf тоже есть MCP-сервер, но с другим охватом: он отдаёт Registry API
BSR (модули, коммиты, метки), включая запись. См.
[EasyP и Buf BSR](/ru/docs/api-service/vs-buf-bsr).
