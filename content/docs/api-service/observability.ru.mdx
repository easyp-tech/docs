## Эндпоинты

| Порт (бинарник / чарт) | Путь | Содержимое |
|---|---|---|
| 23411 / 8081 | `/metrics` | Метрики Prometheus. Всегда включены. |
| 23412 / 8082 | `/live` | Liveness. 200, как только процесс поднялся; больше ничего не проверяет. |
| 23412 / 8082 | `/` | Readiness. 200, пока отвечает PostgreSQL; иначе и во время старта — 503. |

Направляйте liveness-пробы на `/live`, а readiness — на `/`. Если использовать
readiness как liveness, под будет перезапускаться при каждом сбое базы.

## Метрики

Все имена начинаются с `easyp_`. Большинство регистрируются при старте;
помеченные *лениво* появляются после первого события, а метрики кеша — только
при настроенном объектном хранилище.

## Трейсы

Задайте `telemetry.otlp_endpoint` (или `OTEL_EXPORTER_OTLP_ENDPOINT`) — адрес
OTLP gRPC-коллектора. Core, реестр и каждый запуск плагина обёрнуты в спаны;
`pool.Get` записывает время в очереди. Пустой адрес — экспортёр не создаётся и
ничего не пытается отправить.

## Профили

Задайте `telemetry.pyroscope_endpoint` для непрерывного профилирования в
Pyroscope.

## Логи

Структурированный JSON в stdout. При каждом старте пишется
`configuration resolved` с настройками, отличающимися от значений по умолчанию,
секреты скрыты. В системе логов стоит алертить на
`gRPC server is running WITHOUT TLS`, `lowered to the licence tier's limit`,
`licence expired`, `audit enqueue timed out`.

## Алерты

Helm-чарт поставляет `PrometheusRule` (`prometheusRule.enabled=true`, нужны CRD
Prometheus Operator). У каждого алерта есть `runbook_url`: это
`prometheusRule.runbookBaseUrl` плюс якорь с именем алерта.

| Алерт | Срабатывает, когда | Ранбук |
|---|---|---|
| EasypLicenceExpiringSoon | Лицензия истекает в течение `licenceExpiryWarningDays` (14) | [ссылка](/ru/docs/api-service/runbooks#easyplicenceexpiringsoon) |
| EasypLicenceInGrace | `easyp_license_in_grace == 1` 15 мин | [ссылка](/ru/docs/api-service/runbooks#easyplicenceingrace) |
| EasypGenerationsRejected | `rate(easyp_pool_generations_rejected_total[5m]) > 0` 5 мин | [ссылка](/ru/docs/api-service/runbooks#easypgenerationsrejected) |
| EasypGenerationQueueSaturated | `easyp_pool_generations_waiting > 0` 10 мин | [ссылка](/ru/docs/api-service/runbooks#easypgenerationqueuesaturated) |
| EasypPluginCacheAtLimit | объём кеша / лимит > `cacheUsageWarningRatio` (0.95) 30 мин | [ссылка](/ru/docs/api-service/runbooks#easypplugincacheatlimit) |
| EasypAuditEventsLost | `rate(easyp_audit_events_lost_total[5m]) > 0` 5 мин | [ссылка](/ru/docs/api-service/runbooks#easypauditeventslost) |
| EasypAuditMaintenanceStale | нет успешного обслуживания партиций 24 ч | [ссылка](/ru/docs/api-service/runbooks#easypauditmaintenancestale) |
| EasypAuditDefaultPartitionUsed | `easyp_audit_default_partition_used == 1` 15 мин | [ссылка](/ru/docs/api-service/runbooks#easypauditdefaultpartitionused) |
| EasypGenerationErrorRate | доля ошибок > `generationErrorRatio` (0.05) 10 мин | [ссылка](/ru/docs/api-service/runbooks#easypgenerationerrorrate) |
| EasypPanics | `increase(easyp_panics_total[5m]) > 0` | [ссылка](/ru/docs/api-service/runbooks#easyppanics) |
| EasypAuthFailures | `rate(easyp_auth_failures_total[5m]) > authFailureRate` (0.5) 10 мин | [ссылка](/ru/docs/api-service/runbooks#easypauthfailures) |

Compose-стек добавляет алерты хоста и edge, которые считает его собственный Mimir
по тому, что собирает Grafana Alloy, — EasypHostDiskLow, EasypHostDiskFillingUp,
EasypHostMemoryLow, EasypTargetDown, EasypServiceMissing,
EasypCertificateExpiringSoon — в
`deploy/observability/mimir/rules/anonymous/host.yaml`. Они тоже есть в
[Ранбуках](/ru/docs/api-service/runbooks#the-host).

`ServiceMonitor` (`serviceMonitor.enabled=true`) опрашивает `/metrics` каждые
30 с.
