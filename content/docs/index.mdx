EasyP v1 is a modern Protocol Buffers toolkit powered by its own pure-Go compiler (`easyprotoc`, no `protoc` required) with Protobuf Editions 2023 support, 44 lint rules, 69 breaking-change checks, Git-native MVS dependency management, 15 built-in WASM plugins, local and remote code generation, and the `easyp-mcp` stdio server for AI tools.

<Callout type="info">
New here? Start with the [Quickstart](/docs/introduction/quickstart) or [Install EasyP v1](/docs/introduction/install). Upgrading from v0? Follow the [Migration from EasyP v0](/docs/migration/easyp-v0) guide.
</Callout>
