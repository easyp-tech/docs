---
title: "Message Same Message Set Wire Format"
description: "Checks that messages keep the same message_set_wire_format option."
---

- **Rule ID:** `MESSAGE_SAME_MESSAGE_SET_WIRE_FORMAT`
- **Profiles:** `FILE`, `PACKAGE`, `WIRE_JSON`, `WIRE`

This rule checks that a message does not toggle `option message_set_wire_format`. Enabling or disabling MessageSet wire encoding completely changes the binary framing of extensions on that message and breaks compatibility across all four profiles (`FILE`, `PACKAGE`, `WIRE_JSON`, `WIRE`).

## Examples

### Bad

**Before:**

```proto
syntax = "proto2";

package myapi.v1;

message Envelope {
  extensions 100 to max;
}
```

**After:**

```proto
syntax = "proto2";

package myapi.v1;

message Envelope {
  option message_set_wire_format = true;
  extensions 4 to max;
}
```

**Error:**

```text
envelope.proto:5:1: Message "myapi.v1.Envelope" changed message-set encoding. (MESSAGE_SAME_MESSAGE_SET_WIRE_FORMAT)
```

### Good

Keep `message_set_wire_format` unchanged on existing messages:

```proto
syntax = "proto2";

package myapi.v1;

message Envelope {
  extensions 100 to max;
}
```
