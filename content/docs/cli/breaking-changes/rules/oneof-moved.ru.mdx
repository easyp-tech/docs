---
title: "Oneof Moved"
description: "Проверяет, что блоки oneof не переносятся в другой .proto-файл в профиле FILE."
---

- **ID правила:** `ONEOF_MOVED`
- **Профили:** `FILE`

В профиле `FILE` перенос сообщения с настоящим блоком `oneof` в другой `.proto`-файл вызывает срабатывание `ONEOF_MOVED` (в дополнение к `MESSAGE_MOVED`), поскольку сгенерированные типы-обёртки перемещаются в другой файл. Если переносы внутри одного пакета допустимы, используйте профиль `PACKAGE`.

## Примеры

### Неправильно

**До:**

```proto
// File: myapi/v1/auth.proto
syntax = "proto3";

package myapi.v1;

message LoginRequest {
  oneof credentials {
    string password = 1;
    string token = 2;
  }
}
```

**После:**

```proto
// File: myapi/v1/login.proto
syntax = "proto3";

package myapi.v1;

message LoginRequest {
  oneof credentials {
    string password = 1;
    string token = 2;
  }
}
```

**Ошибка:**

```text
myapi/v1/auth.proto:7:3: Oneof "credentials" on "myapi.v1.LoginRequest" was moved from "myapi/v1/auth.proto" to "myapi/v1/login.proto". (ONEOF_MOVED)
```

### Правильно

Оставьте сообщение и его `oneof` в исходном `.proto`-файле при использовании профиля `FILE`:

```proto
// File: myapi/v1/auth.proto
syntax = "proto3";

package myapi.v1;

message LoginRequest {
  oneof credentials {
    string password = 1;
    string token = 2;
  }
}
```
