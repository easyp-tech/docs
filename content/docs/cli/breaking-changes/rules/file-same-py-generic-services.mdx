---
title: "File Same Py Generic Services"
description: "Checks that files keep the same py_generic_services option value."
---

- **Rule ID:** `FILE_SAME_PY_GENERIC_SERVICES`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that the file-level `py_generic_services` option does not change for a file or for any declaration moved to another file in the same package. Changing `py_generic_services` alters whether Python generic service base classes are generated, breaking source compatibility for Python consumers.

## Examples

### Bad

**Before:**

```proto
syntax = "proto3";

package myapi.v1;

option py_generic_services = true;

message User {
  string id = 1;
}
```

**After:**

```proto
syntax = "proto3";

package myapi.v1;

option py_generic_services = false;

message User {
  string id = 1;
}
```

**Error:**

```text
user.proto:1:1: File option py_generic_services changed. (FILE_SAME_PY_GENERIC_SERVICES)
```

### Good

Keep `option py_generic_services` unchanged in the existing package version; change it only in a new major package version (for example, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option py_generic_services = true;

message User {
  string id = 1;
}
```
