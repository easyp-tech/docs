---
title: "File Same Cc Enable Arenas"
description: "Checks that files keep the same cc_enable_arenas option value."
---

- **Rule ID:** `FILE_SAME_CC_ENABLE_ARENAS`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that the file-level `cc_enable_arenas` option does not change for a file or for any declaration moved to another file in the same package. Changing `cc_enable_arenas` alters arena allocation support in generated C++ classes, breaking source compatibility for C++ consumers.

## Examples

### Bad

**Before:**

```proto
syntax = "proto3";

package myapi.v1;

option cc_enable_arenas = true;

message User {
  string id = 1;
}
```

**After:**

```proto
syntax = "proto3";

package myapi.v1;

option cc_enable_arenas = false;

message User {
  string id = 1;
}
```

**Error:**

```text
user.proto:1:1: File option cc_enable_arenas changed. (FILE_SAME_CC_ENABLE_ARENAS)
```

### Good

Keep `option cc_enable_arenas` unchanged in the existing package version; change it only in a new major package version (for example, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option cc_enable_arenas = true;

message User {
  string id = 1;
}
```
