---
title: "File Same Php Metadata Namespace"
description: "Checks that files keep the same php_metadata_namespace option value."
---

- **Rule ID:** `FILE_SAME_PHP_METADATA_NAMESPACE`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that the file-level `php_metadata_namespace` option does not change for a file or for any declaration moved to another file in the same package. Changing `php_metadata_namespace` alters the PHP namespace used for generated descriptor metadata classes, breaking source compatibility for PHP consumers.

## Examples

### Bad

**Before:**

```proto
syntax = "proto3";

package myapi.v1;

option php_metadata_namespace = "Acme\\MyApi\\GPBMetadata";

message User {
  string id = 1;
}
```

**After:**

```proto
syntax = "proto3";

package myapi.v1;

option php_metadata_namespace = "Acme\\Users\\GPBMetadata";

message User {
  string id = 1;
}
```

**Error:**

```text
user.proto:1:1: File option php_metadata_namespace changed. (FILE_SAME_PHP_METADATA_NAMESPACE)
```

### Good

Keep `option php_metadata_namespace` unchanged in the existing package version; change it only in a new major package version (for example, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option php_metadata_namespace = "Acme\\MyApi\\GPBMetadata";

message User {
  string id = 1;
}
```
