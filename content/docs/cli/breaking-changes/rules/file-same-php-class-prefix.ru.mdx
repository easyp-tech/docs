---
title: "File Same Php Class Prefix"
description: "Проверяет, что файлы сохраняют прежнее значение опции php_class_prefix."
---

- **ID правила:** `FILE_SAME_PHP_CLASS_PREFIX`
- **Профили:** `FILE`, `PACKAGE`

Это правило проверяет, что файловая опция `php_class_prefix` не изменилась у файла (а также у объявлений, перенесённых в другой файл того же пакета). Изменение `php_class_prefix` меняет префикс сгенерированных PHP-классов и ломает совместимость сгенерированного кода для PHP.

## Примеры

### Неправильно

**До:**

```proto
syntax = "proto3";

package myapi.v1;

option php_class_prefix = "Acme";

message User {
  string id = 1;
}
```

**После:**

```proto
syntax = "proto3";

package myapi.v1;

option php_class_prefix = "Users";

message User {
  string id = 1;
}
```

**Ошибка:**

```text
user.proto:1:1: File option php_class_prefix changed. (FILE_SAME_PHP_CLASS_PREFIX)
```

### Правильно

Сохраняйте `option php_class_prefix` неизменной в текущей мажорной версии пакета; меняйте её только в новой мажорной версии (например, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option php_class_prefix = "Acme";

message User {
  string id = 1;
}
```
