---
title: "File Same Syntax"
description: "Checks that a file keeps the same syntax or Protobuf edition."
---

- **Rule ID:** `FILE_SAME_SYNTAX`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that a `.proto` file keeps the same `syntax` (`proto2` / `proto3`) and Protobuf `edition` (for example, `"2023"`). Switching syntax or edition changes default presence, enum openness, and generated API conventions.

## Examples

### Bad

**Before:**

```proto
syntax = "proto3";

package myapi.v1;

message User {
  string id = 1;
}
```

**After:**

```proto
edition = "2023";

package myapi.v1;

message User {
  string id = 1;
}
```

**Error:**

```text
user.proto:1:1: File "user.proto" changed syntax from proto3 to editions. (FILE_SAME_SYNTAX)
```

### Good

Preserve the file `syntax` or `edition` within the same major version; adopt a new syntax or edition in a new major package version (for example, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

message User {
  string id = 1;
}
```
