---
title: "Enum Value Same Name"
description: "Проверяет, что существующие значения enum сохраняют прежнее имя для своего номера."
---

- **ID правила:** `ENUM_VALUE_SAME_NAME`
- **Профили:** `FILE`, `PACKAGE`, `WIRE_JSON`

Это правило проверяет, что существующие пары `(имя, номер)` в enum не переименовываются. Переименование значения enum ломает сгенерированные константы и JSON-сериализацию Protobuf (которая использует строковые имена значений). В профиле `WIRE` значения enum передаются только числами, поэтому там это правило не применяется.

## Примеры

### Неправильно

**До:**

```proto
syntax = "proto3";

package myapi.v1;

enum OrderStatus {
  ORDER_STATUS_UNSPECIFIED = 0;
  ORDER_STATUS_PENDING = 1;
  ORDER_STATUS_CONFIRMED = 2;
}
```

**После:**

```proto
syntax = "proto3";

package myapi.v1;

enum OrderStatus {
  ORDER_STATUS_UNSPECIFIED = 0;
  ORDER_STATUS_PENDING = 1;
  ORDER_STATUS_APPROVED = 2; // Переименовано из ORDER_STATUS_CONFIRMED
}
```

**Ошибка:**

```text
order.proto:5:1: Enum value "ORDER_STATUS_CONFIRMED" at number 2 in "myapi.v1.OrderStatus" changed name to "ORDER_STATUS_APPROVED". (ENUM_VALUE_SAME_NAME)
```

### Правильно

Добавьте новое значение enum и пометьте старое как `deprecated`:

```proto
syntax = "proto3";

package myapi.v1;

enum OrderStatus {
  ORDER_STATUS_UNSPECIFIED = 0;
  ORDER_STATUS_PENDING = 1;
  ORDER_STATUS_CONFIRMED = 2 [deprecated = true];
  ORDER_STATUS_APPROVED = 3;
}
```

Либо сохраните исходную пару `(имя, номер)` и добавьте псевдоним через `option allow_alias = true;`, если алиасы разрешены политикой линтинга (см. [`ENUM_NO_ALLOW_ALIAS`](/ru/docs/cli/linter/rules/enum-no-allow-alias)):

```proto
syntax = "proto3";

package myapi.v1;

enum OrderStatus {
  option allow_alias = true;
  ORDER_STATUS_UNSPECIFIED = 0;
  ORDER_STATUS_PENDING = 1;
  ORDER_STATUS_CONFIRMED = 2 [deprecated = true];
  ORDER_STATUS_APPROVED = 2;
}
```
