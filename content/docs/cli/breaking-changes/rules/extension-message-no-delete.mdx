---
title: "Extension Message No Delete"
description: "Checks that messages do not remove or narrow existing extension number ranges."
---

- **Rule ID:** `EXTENSION_MESSAGE_NO_DELETE`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that every extension range previously declared on a message (`extensions 100 to 199;`) remains fully covered by the new extension ranges. Removing or shrinking an extension range breaks downstream schemas that define extensions within those numbers.

## Examples

### Bad

**Before:**

```proto
syntax = "proto2";

package myapi.v1;

message Event {
  optional string id = 1;
  extensions 100 to 199;
}
```

**After:**

```proto
syntax = "proto2";

package myapi.v1;

message Event {
  optional string id = 1;
  extensions 100 to 149;
}
```

**Error:**

```text
event.proto:5:1: Message "myapi.v1.Event" removed or narrowed an extension range. (EXTENSION_MESSAGE_NO_DELETE)
```

### Good

Preserve all existing extension ranges (expanding a range or adding new ranges is compatible):

```proto
syntax = "proto2";

package myapi.v1;

message Event {
  optional string id = 1;
  extensions 100 to 299;
}
```
