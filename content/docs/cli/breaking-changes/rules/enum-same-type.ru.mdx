---
title: "Enum Same Type"
description: "Проверяет, что enum не переключается между открытой (open) и закрытой (closed) семантикой."
---

- **ID правила:** `ENUM_SAME_TYPE`
- **Профили:** `FILE`, `PACKAGE`

Это правило проверяет, что enum не переключается между **открытой** (по умолчанию в `proto3` и Editions 2023 — неизвестные числа сохраняются в самом поле) и **закрытой** семантикой (по умолчанию в `proto2` — неизвестные числа уходят в unknown fields). Смена типа enum меняет рантайм-поведение и сгенерированный код в профилях `FILE` и `PACKAGE`.

## Примеры

### Неправильно

**До:**

```proto
edition = "2023";

package myapi.v1;

enum Status {
  option features.enum_type = OPEN;
  STATUS_UNSPECIFIED = 0;
}
```

**После:**

```proto
edition = "2023";

package myapi.v1;

enum Status {
  option features.enum_type = CLOSED;
  STATUS_UNSPECIFIED = 0;
}
```

**Ошибка:**

```text
status.proto:5:1: Enum "myapi.v1.Status" changed between open and closed semantics. (ENUM_SAME_TYPE)
```

### Правильно

Сохраняйте семантику `OPEN`/`CLOSED` неизменной в рамках текущей мажорной версии:

```proto
edition = "2023";

package myapi.v1;

enum Status {
  option features.enum_type = OPEN;
  STATUS_UNSPECIFIED = 0;
}
```
