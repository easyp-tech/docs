---
title: "File Same Java Package"
description: "Проверяет, что файлы сохраняют прежнее значение опции java_package."
---

- **ID правила:** `FILE_SAME_JAVA_PACKAGE`
- **Профили:** `FILE`, `PACKAGE`

Это правило проверяет, что файловая опция `java_package` не изменилась у файла (а также у объявлений, перенесённых в другой файл того же пакета). Изменение `java_package` меняет имя сгенерированного Java-пакета для всех классов файла и ломает совместимость сгенерированного кода для Java.

## Примеры

### Неправильно

**До:**

```proto
syntax = "proto3";

package myapi.v1;

option java_package = "com.acme.myapi.v1";

message User {
  string id = 1;
}
```

**После:**

```proto
syntax = "proto3";

package myapi.v1;

option java_package = "com.acme.users.v1";

message User {
  string id = 1;
}
```

**Ошибка:**

```text
user.proto:1:1: File option java_package changed. (FILE_SAME_JAVA_PACKAGE)
```

### Правильно

Сохраняйте `option java_package` неизменной в текущей мажорной версии пакета; меняйте её только в новой мажорной версии (например, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option java_package = "com.acme.myapi.v1";

message User {
  string id = 1;
}
```
