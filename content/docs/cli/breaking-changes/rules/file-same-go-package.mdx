---
title: "File Same Go Package"
description: "Checks that files keep the same go_package option value."
---

- **Rule ID:** `FILE_SAME_GO_PACKAGE`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that the file-level `go_package` option does not change for a file or for any declaration moved to another file in the same package. Changing `go_package` alters the generated Go import path and package identifier, breaking source compatibility for Go consumers.

## Examples

### Bad

**Before:**

```proto
syntax = "proto3";

package myapi.v1;

option go_package = "github.com/acme/myapi/gen/v1;myapiv1";

message User {
  string id = 1;
}
```

**After:**

```proto
syntax = "proto3";

package myapi.v1;

option go_package = "github.com/acme/myapi/gen/users/v1;usersv1";

message User {
  string id = 1;
}
```

**Error:**

```text
user.proto:1:1: File option go_package changed. (FILE_SAME_GO_PACKAGE)
```

### Good

Keep `option go_package` unchanged in the existing package version; change it only in a new major package version (for example, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option go_package = "github.com/acme/myapi/gen/v1;myapiv1";

message User {
  string id = 1;
}
```
