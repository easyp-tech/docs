---
title: "Extension Same Number"
description: "Проверяет, что расширения сохраняют прежний номер поля."
---

- **ID правила:** `EXTENSION_SAME_NUMBER`
- **Профили:** `FILE`, `PACKAGE`, `WIRE_JSON`, `WIRE`

Это правило проверяет, что расширение сохраняет прежний номер тега. Изменение номера расширения ломает бинарное декодирование и сгенерированные дескрипторы расширений во всех четырёх профилях (`FILE`, `PACKAGE`, `WIRE_JSON`, `WIRE`).

## Примеры

### Неправильно

**До:**

```proto
syntax = "proto3";

package myapi.v1;

import "google/protobuf/descriptor.proto";

extend google.protobuf.FieldOptions {
  bool sensitive = 50001;
}
```

**После:**

```proto
syntax = "proto3";

package myapi.v1;

import "google/protobuf/descriptor.proto";

extend google.protobuf.FieldOptions {
  bool sensitive = 50002;
}
```

**Ошибка:**

```text
options.proto:8:3: Extension "myapi.v1.sensitive" changed number from 50001 to 50002. (EXTENSION_SAME_NUMBER)
```

### Правильно

Не изменяйте номер тега существующего расширения:

```proto
syntax = "proto3";

package myapi.v1;

import "google/protobuf/descriptor.proto";

extend google.protobuf.FieldOptions {
  bool sensitive = 50001;
}
```
