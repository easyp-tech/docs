---
title: "File Same Java Multiple Files"
description: "Checks that files keep the same java_multiple_files option value."
---

- **Rule ID:** `FILE_SAME_JAVA_MULTIPLE_FILES`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that the file-level `java_multiple_files` option does not change for a file or for any declaration moved to another file in the same package. Changing `java_multiple_files` alters whether top-level messages and enums are generated as separate classes or nested under the outer class, breaking source compatibility for Java consumers.

## Examples

### Bad

**Before:**

```proto
syntax = "proto3";

package myapi.v1;

option java_multiple_files = true;

message User {
  string id = 1;
}
```

**After:**

```proto
syntax = "proto3";

package myapi.v1;

option java_multiple_files = false;

message User {
  string id = 1;
}
```

**Error:**

```text
user.proto:1:1: File option java_multiple_files changed. (FILE_SAME_JAVA_MULTIPLE_FILES)
```

### Good

Keep `option java_multiple_files` unchanged in the existing package version; change it only in a new major package version (for example, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option java_multiple_files = true;

message User {
  string id = 1;
}
```
