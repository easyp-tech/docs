---
title: "File Same Java Outer Classname"
description: "Checks that files keep the same java_outer_classname option value."
---

- **Rule ID:** `FILE_SAME_JAVA_OUTER_CLASSNAME`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that the file-level `java_outer_classname` option does not change for a file or for any declaration moved to another file in the same package. Changing `java_outer_classname` alters the name of the generated Java outer wrapper class, breaking source compatibility for Java consumers.

## Examples

### Bad

**Before:**

```proto
syntax = "proto3";

package myapi.v1;

option java_outer_classname = "UserProto";

message User {
  string id = 1;
}
```

**After:**

```proto
syntax = "proto3";

package myapi.v1;

option java_outer_classname = "UsersProto";

message User {
  string id = 1;
}
```

**Error:**

```text
user.proto:1:1: File option java_outer_classname changed. (FILE_SAME_JAVA_OUTER_CLASSNAME)
```

### Good

Keep `option java_outer_classname` unchanged in the existing package version; change it only in a new major package version (for example, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option java_outer_classname = "UserProto";

message User {
  string id = 1;
}
```
