---
title: "Field No Delete"
description: "Проверяет, что ни одно поле сообщения не было удалено в профилях совместимости исходного кода."
---

- **ID правила:** `FIELD_NO_DELETE`
- **Профили:** `FILE`, `PACKAGE`

Это правило проверяет, что из сообщения не удалено ни одно поле. Удаление поля убирает сгенерированные поля структур и геттеры/сеттеры, что ломает компиляцию клиентского кода.

<Callout type="info">
Директива `reserved` для удалённого номера или имени поля **не** удовлетворяет `FIELD_NO_DELETE` в профилях `FILE` и `PACKAGE`, так как сгенерированные методы доступа всё равно исчезают. Резервирование номера (и имени для JSON) достаточно только для [`FIELD_NO_DELETE_UNLESS_NUMBER_RESERVED`](/ru/docs/cli/breaking-changes/rules/field-no-delete-unless-number-reserved) (`WIRE`, `WIRE_JSON`) и [`FIELD_NO_DELETE_UNLESS_NAME_RESERVED`](/ru/docs/cli/breaking-changes/rules/field-no-delete-unless-name-reserved) (`WIRE_JSON`).
</Callout>

## Примеры

### Неправильно

**До:**

```proto
syntax = "proto3";

package myapi.v1;

message User {
  string name = 1;
  string email = 2;
  int32 age = 3;
  string phone = 4;
}
```

**После:**

```proto
syntax = "proto3";

package myapi.v1;

message User {
  reserved 4;
  reserved "phone";

  string name = 1;
  string email = 2;
  int32 age = 3;
}
```

**Ошибка:**

```text
user.proto:9:3: Field "phone" (4) on "myapi.v1.User" was deleted. (FIELD_NO_DELETE)
```

### Правильно

В профилях `FILE` и `PACKAGE` оставьте поле и пометьте его как `deprecated`:

```proto
syntax = "proto3";

package myapi.v1;

message User {
  string name = 1;
  string email = 2;
  int32 age = 3;
  string phone = 4 [deprecated = true];
}
```

## Стратегия миграции

1. Пометьте поле опцией `[deprecated = true]` и прекратите запись в него в прикладном коде.
2. Если ваша политика использует `WIRE` или `WIRE_JSON`, при удалении поля обязательно зарезервируйте его номер (и имя для `WIRE_JSON`).
3. Если политика использует `FILE` или `PACKAGE`, сохраняйте устаревшее поле до следующей мажорной версии пакета (например, `myapi.v2`).
