---
title: "File Same Cc Enable Arenas"
description: "Проверяет, что файлы сохраняют прежнее значение опции cc_enable_arenas."
---

- **ID правила:** `FILE_SAME_CC_ENABLE_ARENAS`
- **Профили:** `FILE`, `PACKAGE`

Это правило проверяет, что файловая опция `cc_enable_arenas` не изменилась у файла (а также у объявлений, перенесённых в другой файл того же пакета). Изменение `cc_enable_arenas` меняет поддержку arena-аллокации в сгенерированных классах C++ и ломает совместимость сгенерированного кода для C++.

## Примеры

### Неправильно

**До:**

```proto
syntax = "proto3";

package myapi.v1;

option cc_enable_arenas = true;

message User {
  string id = 1;
}
```

**После:**

```proto
syntax = "proto3";

package myapi.v1;

option cc_enable_arenas = false;

message User {
  string id = 1;
}
```

**Ошибка:**

```text
user.proto:1:1: File option cc_enable_arenas changed. (FILE_SAME_CC_ENABLE_ARENAS)
```

### Правильно

Сохраняйте `option cc_enable_arenas` неизменной в текущей мажорной версии пакета; меняйте её только в новой мажорной версии (например, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option cc_enable_arenas = true;

message User {
  string id = 1;
}
```
