---
title: "Enum Moved"
description: "Проверяет, что объявления enum не переносятся в другой .proto-файл в профиле FILE."
---

- **ID правила:** `ENUM_MOVED`
- **Профили:** `FILE`

В профиле `FILE` перенос `enum` из одного `.proto`-файла в другой (даже внутри того же пакета) считается несовместимым, поскольку сгенерированные файловые импорты и заголовки (например, `#include` в C++ или модули Python) зависят от пути файла. Если переносы внутри пакета допустимы, используйте профиль `PACKAGE`.

## Примеры

### Неправильно

**До:**

```proto
// File: myapi/v1/order.proto
syntax = "proto3";

package myapi.v1;

enum OrderStatus {
  ORDER_STATUS_UNSPECIFIED = 0;
}
```

**После:**

```proto
// File: myapi/v1/status.proto
syntax = "proto3";

package myapi.v1;

enum OrderStatus {
  ORDER_STATUS_UNSPECIFIED = 0;
}
```

**Ошибка:**

```text
myapi/v1/order.proto:6:1: Enum "myapi.v1.OrderStatus" was moved from "myapi/v1/order.proto" to "myapi/v1/status.proto". (ENUM_MOVED)
```

### Правильно

Оставьте `enum` в исходном `.proto`-файле при использовании профиля `FILE`:

```proto
// File: myapi/v1/order.proto
syntax = "proto3";

package myapi.v1;

enum OrderStatus {
  ORDER_STATUS_UNSPECIFIED = 0;
}
```
