---
title: "File Same Java Package"
description: "Checks that files keep the same java_package option value."
---

- **Rule ID:** `FILE_SAME_JAVA_PACKAGE`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that the file-level `java_package` option does not change for a file or for any declaration moved to another file in the same package. Changing `java_package` alters the generated Java package name for all classes in the file, breaking source compatibility for Java consumers.

## Examples

### Bad

**Before:**

```proto
syntax = "proto3";

package myapi.v1;

option java_package = "com.acme.myapi.v1";

message User {
  string id = 1;
}
```

**After:**

```proto
syntax = "proto3";

package myapi.v1;

option java_package = "com.acme.users.v1";

message User {
  string id = 1;
}
```

**Error:**

```text
user.proto:1:1: File option java_package changed. (FILE_SAME_JAVA_PACKAGE)
```

### Good

Keep `option java_package` unchanged in the existing package version; change it only in a new major package version (for example, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option java_package = "com.acme.myapi.v1";

message User {
  string id = 1;
}
```
