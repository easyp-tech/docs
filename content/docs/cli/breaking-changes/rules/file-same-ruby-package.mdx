---
title: "File Same Ruby Package"
description: "Checks that files keep the same ruby_package option value."
---

- **Rule ID:** `FILE_SAME_RUBY_PACKAGE`
- **Profiles:** `FILE`, `PACKAGE`

This rule checks that the file-level `ruby_package` option does not change for a file or for any declaration moved to another file in the same package. Changing `ruby_package` alters the generated Ruby module hierarchy, breaking source compatibility for Ruby consumers.

## Examples

### Bad

**Before:**

```proto
syntax = "proto3";

package myapi.v1;

option ruby_package = "Acme::MyApi::V1";

message User {
  string id = 1;
}
```

**After:**

```proto
syntax = "proto3";

package myapi.v1;

option ruby_package = "Acme::Users::V1";

message User {
  string id = 1;
}
```

**Error:**

```text
user.proto:1:1: File option ruby_package changed. (FILE_SAME_RUBY_PACKAGE)
```

### Good

Keep `option ruby_package` unchanged in the existing package version; change it only in a new major package version (for example, `myapi.v2`).

```proto
syntax = "proto3";

package myapi.v1;

option ruby_package = "Acme::MyApi::V1";

message User {
  string id = 1;
}
```
