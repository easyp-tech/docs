---
title: "Проверка несовместимых изменений"
description: "Сравнение protobuf-схем с Git-ссылкой в EasyP v1."
---

`easyp breaking` сравнивает текущие `.proto` с Git-ссылкой и выводит несовместимые изменения, обнаруженные существующим механизмом проверки.

```yaml
# easyp.yaml
version: v1
breaking:
  baseline: git:main
  ignore: [experimental]
```

```bash
easyp breaking --path proto --against main
easyp --format json breaking --path proto
```

`breaking.baseline` выбирает Git-ссылку. Если поле не задано, используется `--against` (по умолчанию `master`). `--path` указывает каталог относительно корня проверки; `--root` меняет этот корень с каталога файла политики. `breaking.ignore` исключает каталоги из проверки.

Пилотная версия v1 сохраняет существующий набор breaking-проверок. `breaking.categories`, `breaking.ignore_unstable` и `breaking.extends` не реализованы и возвращают ошибку, чтобы не менять поведение незаметно. Старый ключ `breaking_check.against_git_ref` CLI v1 не принимает.

Формат политики описан в [справочнике `easyp.yaml`](/ru/docs/reference/easyp-yaml). Для импортов проверка использует корни модуля и зависимостей, найденные для корня проверки. Политика может работать и без манифеста модуля.
