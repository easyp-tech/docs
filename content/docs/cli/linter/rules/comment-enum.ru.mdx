---
title: "Comment Enum"
description: "Это правило проверяет, что enum имеет комментарий."
---

- **ID правила:** `COMMENT_ENUM`
- **Группа:** `COMMENTS`
- **Входит в пресеты (`linters.default`):** `COMMENTS`

Это правило проверяет, что enum имеет комментарий.

## Примеры

### Неправильно

```proto
syntax = "proto3";

enum Foo {
    BAR = 0;
    BAZ = 1;
}
```

### Правильно

```proto
syntax = "proto3";

// Foo enum for bar and baz logic
enum Foo {
    BAR = 0;
    BAZ = 1;
}
```
