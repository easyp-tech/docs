description: "This rule checks that no public imports are used in a proto file."
---

- **Rule ID:** `IMPORT_NO_PUBLIC`
- **Group:** `BASIC`
- **Included in presets (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

This rule checks that no public imports are used in a proto file.


## Examples

### Bad

```proto
syntax = "proto3";

package foo;

import public "bar.proto";
```

### Good

```proto
syntax = "proto3";

package foo;

import "bar.proto";
```
