- **Rule ID:** `PACKAGE_VERSION_SUFFIX`
- **Group:** `DEFAULT`
- **Included in presets (`linters.default`):** `STANDARD`, `COMMENTS`

- **Rule ID:** `PACKAGE_VERSION_SUFFIX`
- **Group:** `DEFAULT`
- **Included in presets (`linters.default`):** `STANDARD`, `COMMENTS`

This rule checks that the package name has at least two dot-separated components and that its last component is a valid version suffix:

- `vN` (for example, `foo.v1`, `acme.users.v2`)
- `vNalpha`, `vNalphaM`, `vNbeta`, `vNbetaM` (for example, `foo.v1alpha1`, `foo.v1beta2`)
- `vNpMalpha`, `vNpMalphaK`, `vNpMbeta`, `vNpMbetaK` (for example, `foo.v1p1alpha1`, `foo.v1p1beta1`)
- `vNtest...` (for example, `foo.v1test`, `foo.v1testfoo`)

All version numbers (`N`, `M`, `K`) must be integers `>= 1`. Underscore-delimited suffixes like `_v1` or single-component packages like `v1` are rejected.

## Examples

### Bad

```proto
syntax = "proto3";

package foo;
```

```proto
syntax = "proto3";

package foo_v1;
```

```proto
syntax = "proto3";

package v1;
```

```proto
syntax = "proto3";

package foo.v0;
```

### Good

```proto
syntax = "proto3";

package foo.v1;
```

```proto
syntax = "proto3";

package foo.v1beta1;
```

```proto
syntax = "proto3";

package foo.v1p1alpha1;
```

```proto
syntax = "proto3";

package foo.v1test;
```
