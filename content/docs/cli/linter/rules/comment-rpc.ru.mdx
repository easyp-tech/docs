- **Группа:** `COMMENTS`
- **Входит в пресеты (`linters.default`):** `COMMENTS`

- **ID правила:** `COMMENT_RPC`
- **Группа:** `COMMENTS`
- **Входит в пресеты (`linters.default`):** `COMMENTS`

Это правило проверяет, что у каждого RPC-метода есть документирующий комментарий непосредственно перед объявлением.

## Примеры

### Неправильно

```proto
syntax = "proto3";

service Foo {
  rpc Bar (BarRequest) returns (BarResponse) {}
  rpc Baz (BazRequest) returns (BazResponse) {}
}
```

### Правильно

```proto
syntax = "proto3";

service Foo {
  // Bar выполняет операцию Bar.
  rpc Bar (BarRequest) returns (BarResponse) {}
  // Baz выполняет операцию Baz.
  rpc Baz (BazRequest) returns (BazResponse) {}
}
```
