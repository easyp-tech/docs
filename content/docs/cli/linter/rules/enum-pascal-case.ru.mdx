---
title: "Enum Pascal Case"
description: "Это правило проверяет, что имена enum написаны в стиле PascalCase."
---

- **ID правила:** `ENUM_PASCAL_CASE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что имена enum написаны в стиле PascalCase.

## Примеры

### Неправильно

```proto
syntax = "proto3";

package foo;

enum foo_bar {
    BAR = 0;
    BAZ = 1;
}
```

### Правильно

```proto
syntax = "proto3";

package foo;

enum FooBar {
    BAR = 0;
    BAZ = 1;
}
```
