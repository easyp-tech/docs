---
title: "Import Used"
description: "This rule checks that all imports are used in a proto file."
---

- **Rule ID:** `IMPORT_USED`
- **Group:** `BASIC`
- **Included in presets (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

This rule checks that all imports are used in a proto file.

## Examples

### Bad

```proto
syntax = "proto3";

package foo;

import "bar.proto";
```

### Good

```proto
syntax = "proto3";

package foo;

import "bar.proto";

message Foo {
    bar.Bar bar = 1;
}
```
