---
title: "Enum Value Upper Snake Case"
description: "Это правило проверяет, что значения enum записаны в стиле UPPER_SNAKE_CASE."
---

- **ID правила:** `ENUM_VALUE_UPPER_SNAKE_CASE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что значения enum записаны в стиле UPPER_SNAKE_CASE.

## Примеры

### Неправильно

```proto
syntax = "proto3";

package foo;

enum Foo {
    barName = 0;
    bazName = 1;
}
```

### Правильно

```proto
syntax = "proto3";

package foo;

enum Foo {
    BAR_NAME = 0;
    BAZ_NAME = 1;
}
```
