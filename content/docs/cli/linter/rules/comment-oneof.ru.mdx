---
title: "Comment Oneof"
description: "Это правило проверяет, что oneof имеет комментарий."
---

- **ID правила:** `COMMENT_ONEOF`
- **Группа:** `COMMENTS`
- **Входит в пресеты (`linters.default`):** `COMMENTS`

Это правило проверяет, что oneof имеет комментарий.

## Примеры

### Неправильно

```proto
syntax = "proto3";

message Foo {
    oneof bar {
        string baz = 1;
        string qux = 2;
    }
}
```

### Правильно

```proto
syntax = "proto3";

message Foo {
    // bar oneof for baz and qux logic
    oneof bar {
        string baz = 1;
        string qux = 2;
    }
}
```
