---
title: "Oneof Lower Snake Case"
description: "Это правило проверяет, что имена oneof записаны в стиле lower_snake_case."
---

- **ID правила:** `ONEOF_LOWER_SNAKE_CASE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что имена oneof записаны в стиле lower_snake_case.

## Примеры

### Неправильно

```proto
syntax = "proto3";

package foo;

message Foo {
    oneof BarName {
        string bar_name = 1;
    }
}
```

### Правильно

```proto
syntax = "proto3";

package foo;

message Foo {
    oneof bar_name {
        string bar_name = 1;
    }
}
```
