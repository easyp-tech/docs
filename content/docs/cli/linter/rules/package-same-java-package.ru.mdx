---
title: "Package Same Java Package"
description: "Это правило проверяет, что все файлы с одним и тем же package используют одно и то же значение опции java_package."
---

- **ID правила:** `PACKAGE_SAME_JAVA_PACKAGE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что все файлы с одним и тем же `package` используют одно и то же значение опции `java_package`.

## Примеры

### Неправильно

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option java_package = "com.example.foo";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option java_package = "com.example.bar";
```

### Правильно

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option java_package = "com.example.foo";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option java_package = "com.example.foo";
```
