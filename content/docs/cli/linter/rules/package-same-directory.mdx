- **Rule ID:** `PACKAGE_SAME_DIRECTORY`
- **Group:** `MINIMAL`
- **Included in presets (`linters.default`):** `MINIMAL`, `BASIC`, `STANDARD`, `COMMENTS`

This module-level rule checks that all `.proto` files declaring the same `package` live in the same directory. If a package is split across multiple directories, every file in that package is reported.

## Examples

### Bad

```proto
// File: foo/v1/user.proto
syntax = "proto3";

package foo.v1;

message User {
  string id = 1;
}
```

```proto
// File: bar/v1/order.proto
syntax = "proto3";

package foo.v1;

message Order {
  string id = 1;
}
```

### Good

```proto
// File: foo/v1/user.proto
syntax = "proto3";

package foo.v1;

message User {
  string id = 1;
}
```

```proto
// File: foo/v1/order.proto
syntax = "proto3";

package foo.v1;

message Order {
  string id = 1;
}
```
