---
title: "Rpc Response Standard Name"
description: "Проверяет, что сообщения ответов RPC имеют имя <Method>Response или <Service><Method>Response."
---

- **ID правила:** `RPC_RESPONSE_STANDARD_NAME`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

- **ID правила:** `RPC_RESPONSE_STANDARD_NAME`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

Это правило проверяет, что имя сообщения ответа каждого RPC соответствует шаблону `<Method>Response` или `<Service><Method>Response` (в PascalCase для имени сервиса и метода).

## Примеры

### Неправильно

```proto
syntax = "proto3";

service FooService {
  rpc GetFoo(GetFooRequest) returns (Foo) {}
}
```

### Правильно

```proto
syntax = "proto3";

service FooService {
  rpc GetFoo(GetFooRequest) returns (GetFooResponse) {}
  rpc ListFoos(FooServiceListFoosRequest) returns (FooServiceListFoosResponse) {}
}
```
