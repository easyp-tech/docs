title: "Rpc No Server Streaming"
description: "Это правило проверяет, что RPC не использует серверный стриминг (ответ не является stream ...)."
---

- **ID правила:** `RPC_NO_SERVER_STREAMING`
- **Группа:** `UNARY_RPC`
- **Входит в пресеты (`linters.default`):** Нет (подключается через `linters.enable`)

Это правило проверяет, что RPC не использует серверный стриминг (ответ не является `stream ...`).

## Примеры

### Неправильно

```proto
syntax = "proto3";

service Foo {
    rpc Bar (BarRequest) returns (stream BarResponse) {}
}
```

### Правильно

```proto
syntax = "proto3";

service Foo {
    rpc Bar (BarRequest) returns (BarResponse) {}
}
```
