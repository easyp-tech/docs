- **ID правила:** `PACKAGE_LOWER_SNAKE_CASE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что имена package записаны в формате lower_snake_case (строчные буквы, при необходимости цифры и символ подчеркивания, без пробелов и заглавных букв).

## Примеры

### Неправильно

```proto
// File: bar/foo.proto
syntax = "proto3";

package FooBar;
```

### Правильно

```proto
// File: bar/foo.proto
syntax = "proto3";

package foo_bar;
```
