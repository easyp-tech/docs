---
title: "Service Pascal Case"
description: "Это правило проверяет, что все имена сервисов написаны в стиле PascalCase."
---

- **ID правила:** `SERVICE_PASCAL_CASE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что все имена сервисов написаны в стиле PascalCase.

## Примеры

### Неправильно

```proto
syntax = "proto3";

service foo_bar {
    rpc get_foo_bar (FooBarRequest) returns (FooBarResponse) {}
}
```

### Правильно

```proto
syntax = "proto3";

service FooBar {
    rpc GetFooBar (FooBarRequest) returns (FooBarResponse) {} 
}
```
