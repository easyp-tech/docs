---
title: "Enum First Value Zero"
description: "Это правило проверяет, что первое значение enum равно нулю."
---

- **ID правила:** `ENUM_FIRST_VALUE_ZERO`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что первое значение enum равно нулю.

## Примеры

### Неправильно

```proto
syntax = "proto3";

package foo;

enum Foo {
    BAR = 1;
    BAZ = 2;
}
```

### Правильно

```proto
syntax = "proto3";

package foo;

enum Foo {
    BAR = 0;
    BAZ = 1;
}
```
