---
title: "Rpc No Client Streaming"
description: "This rule checks that rpc has no client streaming."
---

- **Rule ID:** `RPC_NO_CLIENT_STREAMING`
- **Group:** `UNARY_RPC`
- **Included in presets (`linters.default`):** None (opt-in via `linters.enable`)

This rule checks that rpc has no client streaming.

## Examples

### Bad

```proto
syntax = "proto3";

service Foo {
    rpc Bar (stream BarRequest) returns (BarResponse) {}
}
```

### Good

```proto
syntax = "proto3";

service Foo {
    rpc Bar (BarRequest) returns (BarResponse) {}
}
```
