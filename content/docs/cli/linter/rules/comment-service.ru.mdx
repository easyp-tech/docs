---

- **ID правила:** `COMMENT_SERVICE`
- **Группа:** `COMMENTS`
- **Входит в пресеты (`linters.default`):** `COMMENTS`

Это правило проверяет, что сервис имеет комментарий.

## Примеры

### Неправильно

```proto
syntax = "proto3";

service Foo {
    rpc Bar (BarRequest) returns (BarResponse) {}
}
```

### Правильно

```proto
syntax = "proto3";

// Foo service for bar logic
service Foo {
    // Bar rpc for bar logic 
    rpc Bar (BarRequest) returns (BarResponse) {}
}
```
