---
title: "Rpc Request Standard Name"
---

Categories:
- **MINIMAL**
- **BASIC**
- **DEFAULT**

This rule checks that all RPC request messages are named `MethodRequest`.

## Examples

### Bad

```proto
syntax = "proto3";

service Foo {
    rpc GetFoo (FooRequest) returns (FooResponse) {}
}
```

### Good

```proto
syntax = "proto3";

service Foo {
    rpc GetFoo (GetFooRequest) returns (FooResponse) {}
}
```
