- **Rule ID:** `RPC_REQUEST_STANDARD_NAME`
- **Group:** `DEFAULT`
- **Included in presets (`linters.default`):** `STANDARD`, `COMMENTS`

- **Rule ID:** `RPC_REQUEST_STANDARD_NAME`
- **Group:** `DEFAULT`
- **Included in presets (`linters.default`):** `STANDARD`, `COMMENTS`

This rule checks that every RPC request message name follows either `<Method>Request` or `<Service><Method>Request` (using PascalCase for both the service and RPC names).

## Examples

### Bad

```proto
syntax = "proto3";

service FooService {
  rpc GetFoo(FooRequest) returns (GetFooResponse) {}
}
```

### Good

```proto
syntax = "proto3";

service FooService {
  rpc GetFoo(GetFooRequest) returns (GetFooResponse) {}
  rpc ListFoos(FooServiceListFoosRequest) returns (FooServiceListFoosResponse) {}
}
```
