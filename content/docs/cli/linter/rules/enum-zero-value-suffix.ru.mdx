- **ID правила:** `ENUM_ZERO_VALUE_SUFFIX`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

- **ID правила:** `ENUM_ZERO_VALUE_SUFFIX`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

Это правило проверяет, что каждое значение enum с номером `0` оканчивается на `_NONE` либо на пользовательский суффикс из `linters-settings.ENUM_ZERO_VALUE_SUFFIX.suffix` (можно указывать с ведущим подчёркиванием или без него).

## Конфигурация

```yaml
version: v1
linters-settings:
  ENUM_ZERO_VALUE_SUFFIX:
    suffix: UNSPECIFIED
```

## Примеры

### Неправильно

```proto
syntax = "proto3";

enum Foo {
  FOO_BAR = 0;
}
```

### Правильно

С суффиксом по умолчанию (`NONE`):

```proto
syntax = "proto3";

enum Foo {
  FOO_NONE = 0;
}
```

С настройкой `suffix: UNSPECIFIED`:

```proto
syntax = "proto3";

enum Foo {
  FOO_UNSPECIFIED = 0;
}
```
