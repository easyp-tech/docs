- **Rule ID:** `FIELD_LOWER_SNAKE_CASE`
- **Group:** `BASIC`
- **Included in presets (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

This rule checks that field names of messages are in lower_snake_case.

## Examples

### Bad

```proto
syntax = "proto3";

package foo;

message Foo {
    string BarName = 1;
}
```

### Good

```proto
syntax = "proto3";

package foo;

message Foo {
    string bar_name = 1;
}
```
