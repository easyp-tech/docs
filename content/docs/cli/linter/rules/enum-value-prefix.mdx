---
title: "Enum Value Prefix"
description: "This rule checks that all enum values are prefixed with the enum name."
---

- **Rule ID:** `ENUM_VALUE_PREFIX`
- **Group:** `DEFAULT`
- **Included in presets (`linters.default`):** `STANDARD`, `COMMENTS`

This rule checks that all enum values are prefixed with the enum name.

## Examples

### Bad

```proto
syntax = "proto3";

enum Foo {
    BAR = 0;
}
```

### Good

```proto
syntax = "proto3";

enum Foo {
    FOO_BAR = 0;
}
```
