---

- **ID правила:** `DIRECTORY_SAME_PACKAGE`
- **Группа:** `MINIMAL`
- **Входит в пресеты (`linters.default`):** `MINIMAL`, `BASIC`, `STANDARD`, `COMMENTS`

- **ID правила:** `DIRECTORY_SAME_PACKAGE`
- **Группа:** `MINIMAL`
- **Входит в пресеты (`linters.default`):** `MINIMAL`, `BASIC`, `STANDARD`, `COMMENTS`

Это правило уровня модуля проверяет, что все `.proto`-файлы в одном каталоге объявляют одинаковый `package`. Если в каталоге находятся файлы с разными пакетами (или часть файлов без `package`), ошибка выдаётся для каждого файла в этом каталоге.

## Примеры

### Неправильно

```proto
// File: foo/v1/user.proto
syntax = "proto3";

package foo.v1;

message User {
  string id = 1;
}
```

```proto
// File: foo/v1/order.proto
syntax = "proto3";

package bar.v1;

message Order {
  string id = 1;
}
```

### Правильно

```proto
// File: foo/v1/user.proto
syntax = "proto3";

package foo.v1;

message User {
  string id = 1;
}
```

```proto
// File: foo/v1/order.proto
syntax = "proto3";

package foo.v1;

message Order {
  string id = 1;
}
```
