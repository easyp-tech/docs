---

- **ID правила:** `PACKAGE_SAME_RUBY_PACKAGE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

- **ID правила:** `PACKAGE_SAME_RUBY_PACKAGE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило уровня модуля проверяет, что все файлы с одинаковым `package` задают одинаковое значение опции `ruby_package`.

## Примеры

### Неправильно

```proto
// File: pkg/foo.proto
syntax = "proto3";

package pkg;

option ruby_package = "Foo";
```

```proto
// File: pkg/bar.proto
syntax = "proto3";

package pkg;

option ruby_package = "Bar";
```

### Правильно

```proto
// File: pkg/foo.proto
syntax = "proto3";

package pkg;

option ruby_package = "Foo";
```

```proto
// File: pkg/bar.proto
syntax = "proto3";

package pkg;

option ruby_package = "Foo";
```
