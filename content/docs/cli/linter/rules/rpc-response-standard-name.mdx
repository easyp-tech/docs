title: "Rpc Response Standard Name"
description: "Checks that RPC response messages are named <Method>Response or <Service><Method>Response."
---

- **Rule ID:** `RPC_RESPONSE_STANDARD_NAME`
- **Group:** `DEFAULT`
- **Included in presets (`linters.default`):** `STANDARD`, `COMMENTS`

- **Rule ID:** `RPC_RESPONSE_STANDARD_NAME`
- **Group:** `DEFAULT`
- **Included in presets (`linters.default`):** `STANDARD`, `COMMENTS`

This rule checks that every RPC response message name follows either `<Method>Response` or `<Service><Method>Response` (using PascalCase for both the service and RPC names).

## Examples

### Bad

```proto
syntax = "proto3";

service FooService {
  rpc GetFoo(GetFooRequest) returns (Foo) {}
}
```

### Good

```proto
syntax = "proto3";

service FooService {
  rpc GetFoo(GetFooRequest) returns (GetFooResponse) {}
  rpc ListFoos(FooServiceListFoosRequest) returns (FooServiceListFoosResponse) {}
}
```
