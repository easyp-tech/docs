---
title: "Enum Pascal Case"
description: "This rule checks that enum names are in PascalCase."
---

- **Rule ID:** `ENUM_PASCAL_CASE`
- **Group:** `BASIC`
- **Included in presets (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

This rule checks that enum names are in PascalCase.

## Examples

### Bad

```proto
syntax = "proto3";

package foo;

enum foo_bar {
    BAR = 0;
    BAZ = 1;
}
```

### Good

```proto
syntax = "proto3";

package foo;

enum FooBar {
    BAR = 0;
    BAZ = 1;
}
```
