---
title: "Package Defined"
description: "Это правило проверяет, что во всех файлах присутствует директива package."
---

- **ID правила:** `PACKAGE_DEFINED`
- **Группа:** `MINIMAL`
- **Входит в пресеты (`linters.default`):** `MINIMAL`, `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что во всех файлах присутствует директива package.

## Примеры

### Неправильно

```proto
syntax = "proto3";

message Foo {
    string bar = 1;
}

```

### Правильно

```proto
syntax = "proto3";

package foo;

message Foo {
    string bar = 1;
}
```
