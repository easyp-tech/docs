---

- **Rule ID:** `COMMENT_ENUM_VALUE`
- **Group:** `COMMENTS`
- **Included in presets (`linters.default`):** `COMMENTS`

This rule checks that enum values have a comment.

## Examples

### Bad

```proto
syntax = "proto3";

enum Foo {
    BAR = 0;
    BAZ = 1;
}
```

### Good

```proto

syntax = "proto3";

enum Foo {
    // BAR value for bar logic
    BAR = 0; 
    // BAZ value for baz logic
    BAZ = 1; 
}
```
