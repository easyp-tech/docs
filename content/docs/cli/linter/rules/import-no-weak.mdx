---

- **Rule ID:** `IMPORT_NO_WEAK`
- **Group:** `BASIC`
- **Included in presets (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

This rule checks that no weak imports are used in a proto file.


## Examples

### Bad

```proto
syntax = "proto2";

package foo;

import weak "bar.proto";
```

### Good

```proto
syntax = "proto2";

package foo;

import "bar.proto";
```
