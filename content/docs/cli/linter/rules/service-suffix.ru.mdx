- **ID правила:** `SERVICE_SUFFIX`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

- **ID правила:** `SERVICE_SUFFIX`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

Это правило проверяет, что имена всех `service` оканчиваются на `Service` либо на пользовательский суффикс из `linters-settings.SERVICE_SUFFIX.suffix`.

## Конфигурация

```yaml
version: v1
linters-settings:
  SERVICE_SUFFIX:
    suffix: API
```

## Примеры

### Неправильно

```proto
syntax = "proto3";

service Foo {
  rpc Bar(BarRequest) returns (BarResponse);
}
```

### Правильно

С суффиксом по умолчанию (`Service`):

```proto
syntax = "proto3";

service FooService {
  rpc Bar(BarRequest) returns (BarResponse);
}
```

С настройкой `suffix: API`:

```proto
syntax = "proto3";

service FooAPI {
  rpc Bar(BarRequest) returns (BarResponse);
}
```
