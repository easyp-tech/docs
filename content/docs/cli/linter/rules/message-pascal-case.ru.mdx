---
title: "Message Pascal Case"
description: "Это правило проверяет, что имена сообщений (message) записаны в стиле PascalCase."
---

- **ID правила:** `MESSAGE_PASCAL_CASE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что имена сообщений (message) записаны в стиле PascalCase.

## Примеры

### Неправильно

```proto
syntax = "proto3";

package foo;

message foo_bar {
    string bar_name = 1;
}
```

### Правильно

```proto
syntax = "proto3";

package foo;

message FooBar {
    string bar_name = 1;
}
```
