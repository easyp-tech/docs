---
title: "Import No Public"
description: "Это правило проверяет, что в proto-файле не используются public импорты (оператор import public \"...\")."
---

- **ID правила:** `IMPORT_NO_PUBLIC`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что в proto-файле не используются `public` импорты (оператор `import public "..."`).

## Примеры

### Неправильно

```proto
syntax = "proto3";

package foo;

import public "bar.proto";
```

### Правильно

```proto
syntax = "proto3";

package foo;

import "bar.proto";
```
