---
title: "Package Same Java Package"
description: "This rule checks that all files with a given package are in the same Java package."
---

- **Rule ID:** `PACKAGE_SAME_JAVA_PACKAGE`
- **Group:** `BASIC`
- **Included in presets (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

This rule checks that all files with a given package are in the same Java package.

## Examples

### Bad

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option java_package = "com.example.foo";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option java_package = "com.example.bar";
```

### Good

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option java_package = "com.example.foo";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option java_package = "com.example.foo";
```
