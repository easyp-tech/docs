---
title: "Package Same Php Namespace"
description: "Это правило проверяет, что все файлы с одним и тем же package используют одно и то же значение опции php_namespace."
---

- **ID правила:** `PACKAGE_SAME_PHP_NAMESPACE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что все файлы с одним и тем же `package` используют одно и то же значение опции `php_namespace`.

## Примеры

### Неправильно

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option php_namespace = "Foo\\Bar";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option php_namespace = "Foo\\Baz";
```

### Правильно

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option php_namespace = "Foo\\Bar";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option php_namespace = "Foo\\Bar";
```
