---
title: "Package Same Go Package"
description: "Это правило проверяет, что все файлы с одним и тем же package используют одно и то же значение опции go_package."
---

- **ID правила:** `PACKAGE_SAME_GO_PACKAGE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что все файлы с одним и тем же package используют одно и то же значение опции `go_package`.

## Примеры

### Неправильно

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option go_package = "example.com/foo/bar";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option go_package = "example.com/foo/baz";
```

### Правильно

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option go_package = "example.com/foo/bar";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option go_package = "example.com/foo/bar";
```
