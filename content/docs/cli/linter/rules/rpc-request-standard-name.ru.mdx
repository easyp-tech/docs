title: "Rpc Request Standard Name"
description: "Проверяет, что сообщения запросов RPC имеют имя <Method>Request или <Service><Method>Request."
---

- **ID правила:** `RPC_REQUEST_STANDARD_NAME`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

- **ID правила:** `RPC_REQUEST_STANDARD_NAME`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

Это правило проверяет, что имя сообщения запроса каждого RPC соответствует шаблону `<Method>Request` или `<Service><Method>Request` (в PascalCase для имени сервиса и метода).

## Примеры

### Неправильно

```proto
syntax = "proto3";

service FooService {
  rpc GetFoo(FooRequest) returns (GetFooResponse) {}
}
```

### Правильно

```proto
syntax = "proto3";

service FooService {
  rpc GetFoo(GetFooRequest) returns (GetFooResponse) {}
  rpc ListFoos(FooServiceListFoosRequest) returns (FooServiceListFoosResponse) {}
}
```
