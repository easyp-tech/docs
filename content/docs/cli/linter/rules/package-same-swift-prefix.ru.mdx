---
title: "Package Same Swift Prefix"
description: "Это правило проверяет, что все файлы с одним и тем же package используют один и тот же swift_prefix."
---

- **ID правила:** `PACKAGE_SAME_SWIFT_PREFIX`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что все файлы с одним и тем же package используют один и тот же `swift_prefix`.

## Примеры

### Неправильно

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option swift_prefix = "Foo";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option swift_prefix = "Bar";
```

### Правильно

```proto
// File: pkg/foo.proto

syntax = "proto3";

package pkg;

option swift_prefix = "Foo";
```

```proto
// File: pkg/bar.proto

syntax = "proto3";

package pkg;

option swift_prefix = "Foo";
```
