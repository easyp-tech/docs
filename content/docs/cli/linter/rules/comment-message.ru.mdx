---
title: "Comment Message"
description: "Это правило проверяет, что message имеет комментарий."
---

- **ID правила:** `COMMENT_MESSAGE`
- **Группа:** `COMMENTS`
- **Входит в пресеты (`linters.default`):** `COMMENTS`

Это правило проверяет, что message имеет комментарий.

## Примеры

### Неправильно

```proto
syntax = "proto3";

message Foo {
    string bar = 1;
    string baz = 2;
}
```

### Правильно

```proto
syntax = "proto3";

// Foo message for bar and baz logic
message Foo {
    // bar field for bar logic 
    string bar = 1; 
    // baz field for baz logic
    string baz = 2; 
}
```
