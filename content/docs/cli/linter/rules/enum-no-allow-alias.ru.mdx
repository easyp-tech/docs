---
title: "Enum No Allow Alias"
description: "Это правило проверяет, что опция allow_alias не установлена в значение true внутри enum."
---

- **ID правила:** `ENUM_NO_ALLOW_ALIAS`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что опция `allow_alias` не установлена в значение `true` внутри enum.

## Примеры

### Неправильно

```proto
syntax = "proto3";

package foo;

enum Foo {
    option allow_alias = true;
    BAR = 0;
    BAZ = 1;
}
```

### Правильно

```proto
syntax = "proto3";

package foo;

enum Foo {
    BAR = 0;
    BAZ = 1;
}
```
