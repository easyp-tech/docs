---
title: "Rpc No Client Streaming"
description: "Это правило проверяет, что RPC не использует клиентский стриминг (запрос не является stream ...)."
---

- **ID правила:** `RPC_NO_CLIENT_STREAMING`
- **Группа:** `UNARY_RPC`
- **Входит в пресеты (`linters.default`):** Нет (подключается через `linters.enable`)

Это правило проверяет, что RPC не использует клиентский стриминг (запрос не является `stream ...`).

## Примеры

### Неправильно

```proto
syntax = "proto3";

service Foo {
    rpc Bar (stream BarRequest) returns (BarResponse) {}
}
```

### Правильно

```proto
syntax = "proto3";

service Foo {
    rpc Bar (BarRequest) returns (BarResponse) {}
}
```
