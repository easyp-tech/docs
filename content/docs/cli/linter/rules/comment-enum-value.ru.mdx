---
title: "Comment Enum Value"
description: "Это правило проверяет, что все значения enum имеют комментарий."
---

- **ID правила:** `COMMENT_ENUM_VALUE`
- **Группа:** `COMMENTS`
- **Входит в пресеты (`linters.default`):** `COMMENTS`

Это правило проверяет, что все значения enum имеют комментарий.

## Примеры

### Неправильно

```proto
syntax = "proto3";

enum Foo {
    BAR = 0;
    BAZ = 1;
}
```

### Правильно

```proto
syntax = "proto3";

enum Foo {
    // BAR value for bar logic
    BAR = 0;
    // BAZ value for baz logic
    BAZ = 1;
}
```
