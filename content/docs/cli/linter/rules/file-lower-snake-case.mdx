- **Rule ID:** `FILE_LOWER_SNAKE_CASE`
- **Group:** `DEFAULT`
- **Included in presets (`linters.default`):** `STANDARD`, `COMMENTS`

This rule checks that all files are in lower_snake_case.

## Examples

### Bad

```proto
// File: bar/FooBaz.proto

syntax = "proto3";
```

### Good

```proto
// File: bar/foo_baz.proto

syntax = "proto3";
```
