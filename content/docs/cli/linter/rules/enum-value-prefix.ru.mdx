---

- **ID правила:** `ENUM_VALUE_PREFIX`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

Это правило проверяет, что все значения enum имеют префикс, совпадающий с именем enum.

## Примеры

### Неправильно

```proto
syntax = "proto3";

enum Foo {
    BAR = 0;
}
```

### Правильно

```proto
syntax = "proto3";

enum Foo {
    FOO_BAR = 0;
}
```
