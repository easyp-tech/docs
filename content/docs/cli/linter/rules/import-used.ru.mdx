---

- **ID правила:** `IMPORT_USED`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что все импорты используются в proto-файле.

## Примеры

### Неправильно

```proto
syntax = "proto3";

package foo;

import "bar.proto";
```

### Правильно

```proto
syntax = "proto3";

package foo;

import "bar.proto";

message Foo {
    bar.Bar bar = 1;
}
```
