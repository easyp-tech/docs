- **ID правила:** `FILE_LOWER_SNAKE_CASE`
- **Группа:** `DEFAULT`
- **Входит в пресеты (`linters.default`):** `STANDARD`, `COMMENTS`

Это правило проверяет, что все файлы имеют имя в формате lower_snake_case (только строчные буквы, цифры и символ подчеркивания, без пробелов и заглавных букв).

## Примеры

### Неправильно

```proto
// File: bar/FooBaz.proto

syntax = "proto3";
```

### Правильно

```proto
// File: bar/foo_baz.proto

syntax = "proto3";
```
