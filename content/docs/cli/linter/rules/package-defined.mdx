- **Rule ID:** `PACKAGE_DEFINED`
- **Group:** `MINIMAL`
- **Included in presets (`linters.default`):** `MINIMAL`, `BASIC`, `STANDARD`, `COMMENTS`

This rule checks that all files have a package declaration.

## Examples

### Bad

```proto
syntax = "proto3";

message Foo {
    string bar = 1;
}

```

### Good

```proto
syntax = "proto3";

package foo;

message Foo {
    string bar = 1;
}
```
