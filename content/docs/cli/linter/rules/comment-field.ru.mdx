---
title: "Comment Field"
description: "Это правило проверяет, что все поля сообщений имеют комментарий."
---

- **ID правила:** `COMMENT_FIELD`
- **Группа:** `COMMENTS`
- **Входит в пресеты (`linters.default`):** `COMMENTS`

Это правило проверяет, что все поля сообщений имеют комментарий.

## Примеры

### Неправильно

```proto
syntax = "proto3";

message Foo {
    string bar = 1;
    string baz = 2;
}
```

### Правильно

```proto
syntax = "proto3";

message Foo {
    // bar field for bar logic
    string bar = 1;
    // baz field for baz logic
    string baz = 2;
}
```
