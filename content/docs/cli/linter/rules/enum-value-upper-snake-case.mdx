- **Rule ID:** `ENUM_VALUE_UPPER_SNAKE_CASE`
- **Group:** `BASIC`
- **Included in presets (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

This rule checks that enum values are in UPPER_SNAKE_CASE.

## Examples

### Bad

```proto
syntax = "proto3";

package foo;

enum Foo {
    barName = 0;
    bazName = 1;
}
```

### Good

```proto
syntax = "proto3";

package foo;

enum Foo {
    BAR_NAME = 0;
    BAZ_NAME = 1;
}
```
