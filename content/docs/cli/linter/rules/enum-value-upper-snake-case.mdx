---
title: "Enum Value Upper Snake Case"
---

Categories:
- **MINIMAL**
- **BASIC**
- **DEFAULT**

This rule checks that enum values are in UPPER_SNAKE_CASE.

## Examples

### Bad

```proto
syntax = "proto3";

package foo;

enum Foo {
    barName = 0;
    bazName = 1;
}
```

### Good

```proto
syntax = "proto3";

package foo;

enum Foo {
    BAR_NAME = 0;
    BAZ_NAME = 1;
}
```
