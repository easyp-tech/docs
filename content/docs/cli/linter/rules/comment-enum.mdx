- **Rule ID:** `COMMENT_ENUM`
- **Group:** `COMMENTS`
- **Included in presets (`linters.default`):** `COMMENTS`

This rule checks that enum has a comment.

## Examples

### Bad

```proto
syntax = "proto3";

enum Foo {
    BAR = 0;
    BAZ = 1;
}
```

### Good

```proto
syntax = "proto3";

// Foo enum for bar and baz logic
enum Foo {
    BAR = 0; 
    BAZ = 1; 
}
```
