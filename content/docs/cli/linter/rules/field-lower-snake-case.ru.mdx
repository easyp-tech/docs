---
title: "Field Lower Snake Case"
description: "Это правило проверяет, что имена полей сообщений записаны в стиле lower_snake_case."
---

- **ID правила:** `FIELD_LOWER_SNAKE_CASE`
- **Группа:** `BASIC`
- **Входит в пресеты (`linters.default`):** `BASIC`, `STANDARD`, `COMMENTS`

Это правило проверяет, что имена полей сообщений записаны в стиле lower_snake_case.

## Примеры

### Неправильно

```proto
syntax = "proto3";

package foo;

message Foo {
    string BarName = 1;
}
```

### Правильно

```proto
syntax = "proto3";

package foo;

message Foo {
    string bar_name = 1;
}
```
