---
title: "Генератор"
description: "Генерация кода из целых protobuf-модулей в пилотной версии EasyP v1."
---

`easyp generate` ищет `easyp.gen.yaml` внутри текущего каталога, выбирает целые модули, компилирует их `.proto` и запускает перечисленные плагины. Имена модулей, корни исходников и версии зависимостей берутся из `protobuf.mod` и `protobuf.lock`.

## Настройка модуля

```text
# protobuf.mod
module github.com/acme/contracts
roots proto
require github.com/acme/shared v1.2.0
```

```yaml
# easyp.gen.yaml
version: v1
generate:
  modules: [github.com/acme/contracts]
plugins:
  - name: go
    out: ./gen/go
    opts:
      paths: source_relative
  - name: go-grpc
    out: ./gen/go
    opts:
      paths: source_relative
```

```bash
easyp mod tidy
easyp generate
```

Если `generate.modules` не указан, выбирается ближайший `protobuf.mod`. Элемент списка может быть путём к локальному модулю относительно репозитория или именем зависимости из lock. Поле `generate.packages` оставлено для будущей фильтрации пакетов; непустое значение пока вызывает ошибку.

## Выбор проекта и дескрипторы

```bash
easyp generate --project backend
easyp generate --descriptor_set_out descriptors.pb --include_imports
```

`--project` выбирает один каталог потребителя с `easyp.gen.yaml`. `--include_imports` добавляет транзитивные импорты в набор дескрипторов. Флагов `--path` и `--root` у команды v1 нет: корни исходников объявляются в `protobuf.mod`.

## Плагины и managed mode

`plugins[].name` выбирает локальный исполняемый файл или встроенный WASM-плагин. Встроенные плагины выбираются существующим resolver. Для удалённого плагина указываются `remote` и отдельный зафиксированный SemVer в `version`. Выходные каталоги задаются относительно файла генерации.

Прежние правила managed mode доступны в `generate.managed`, в том числе селекторы по модулю, пакету, пути и полю. `options.go.package_prefix` задаёт префикс Go-пакетов; корневой `easyp.gen.yaml` может предоставить значение по умолчанию вложенным конфигам. Подробности — в [справочнике `easyp.gen.yaml`](/ru/docs/reference/easyp-gen-yaml).

Репозитории зависимостей могут описывать корни `.proto` в EasyP v1, старом EasyP, Buf v1 или Buf v2. Конфиг потребителя при этом остаётся v1.
