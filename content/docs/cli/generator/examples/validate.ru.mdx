---
title: "Генерация кода валидации"
description: "Локальный плагин валидации в EasyP v1."
---

Если `.proto` импортируют аннотации валидации, добавьте Git-модуль с этими файлами в `protobuf.mod`. Плагин запускается через `easyp.gen.yaml`:

```yaml
version: v1
generate:
  modules: [github.com/acme/contracts]
plugins:
  - name: go
    out: ./gen/go
    opts:
      paths: source_relative
  - name: validate
    out: ./gen/go
    opts:
      lang: go
```

Добавьте `protoc-gen-go` и `protoc-gen-validate` в `PATH`, затем выполните:

```bash
easyp mod tidy
easyp generate
```

`easyp mod tidy` фиксирует зависимость схемы в `protobuf.lock`; генератор находит её импорты через lock. Версия локального плагина определяется исполняемым файлом в `PATH`.
