---
title: "Генерация gRPC-Gateway"
description: "Запуск плагина gRPC-Gateway через конфиг EasyP v1."
---

Если `.proto` модуля используют аннотации gRPC-Gateway, перечислите модуль и плагины в `easyp.gen.yaml`:

```yaml
version: v1
generate:
  modules: [github.com/acme/contracts]
plugins:
  - name: go
    out: ./gen/go
    opts:
      paths: source_relative
  - name: go-grpc
    out: ./gen/go
    opts:
      paths: source_relative
  - name: grpc-gateway
    out: ./gen/go
    opts:
      paths: source_relative
```

Добавьте соответствующие исполняемые файлы `protoc-gen-*` в `PATH`. В `protobuf.mod` потребителя объявите Git-модуль, содержащий `google/api/annotations.proto`, затем выполните `easyp mod tidy` и `easyp generate`. Импорт будет найден в корнях зафиксированной зависимости.

Имя плагина относится только к генерации; версии зависимостей схем указываются в `protobuf.mod`, а не в `easyp.gen.yaml`. См. [добавление зависимости](/ru/docs/guides/adding-dependency).
