---
title: "Генерация Go-кода"
description: "Минимальная конфигурация EasyP v1 с локальными Go-плагинами."
---

Объявите корень исходников в `protobuf.mod`:

```text
module github.com/acme/contracts
roots proto
```

Выберите модуль и плагины в `easyp.gen.yaml`:

```yaml
version: v1
generate:
  modules: [github.com/acme/contracts]
plugins:
  - name: go
    out: ./gen/go
    opts:
      paths: source_relative
  - name: go-grpc
    out: ./gen/go
    opts:
      paths: source_relative
```

Добавьте `protoc-gen-go` и `protoc-gen-go-grpc` в `PATH`, затем выполните `easyp generate`. Go import path задаётся опцией `go_package` в `.proto` или managed-опцией `options.go.package_prefix`. Подробности — в [справочнике managed mode](/ru/docs/reference/easyp-gen-yaml).

Имена `go` и `go-grpc` обозначают плагины. У генератора v1 нет `generate.inputs` или флага `--path`: исходники берутся из корней выбранного модуля.
