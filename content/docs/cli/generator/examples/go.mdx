---
title: "Generate Go code"
description: "A minimal EasyP v1 generator using local Go plugins."
---

Declare the source root in `protobuf.mod`:

```text
module github.com/acme/contracts
roots proto
```

Select that module and the plugins in `easyp.gen.yaml`:

```yaml
version: v1
generate:
  modules: [github.com/acme/contracts]
plugins:
  - name: go
    out: ./gen/go
    opts:
      paths: source_relative
  - name: go-grpc
    out: ./gen/go
    opts:
      paths: source_relative
```

Place `protoc-gen-go` and `protoc-gen-go-grpc` on `PATH`, then run `easyp generate`. A `go_package` option in each source file, or a managed `options.go.package_prefix`, supplies the Go import path. See the [managed options reference](/docs/reference/easyp-gen-yaml).

The `go` and `go-grpc` names identify plugins; the v1 generator has no `generate.inputs` or `--path` option. Its inputs come from the selected module's roots.
